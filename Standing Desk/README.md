# Motorized Standing Desk (Hand-Crank)

**Collaborative project** — designed with a project partner in **SolidWorks**.

## Overview
A fully custom standing desk that adjusts height via a hand-crank-driven gear system built into the legs — no pre-made lift mechanism or purchased components.

## Key Features
- **Hand-crank height adjustment**: an internal gear system in each leg converts crank rotation into vertical lift.
- **Integrated accessories**, all custom-designed as part of the assembly:
  - Cable management holder
  - Desk lamp mount
  - Headphone stand
  - Storage cabinet
  - Additional accessory components

## Design Approach
An educational project built to learn CAD assembly and mating — every component **except the gears themselves** was designed from scratch, with no external/pre-made parts. The final assembly spans **10+ distinct mechanical components**, requiring careful mating and tolerancing across the full desk structure.

## Skills Demonstrated
- Multi-component assembly design and mating in SolidWorks
- Mechanical linkage design (crank-to-lift gear system)
- Integration of multiple sub-systems (structural, storage, and accessory components) into a single cohesive product
- Collaborative CAD workflow across a large, multi-part assembly

## Challenges & Solutions
- **Challenge:** Coordinating 10+ interdependent components meant that changes to one part (e.g., leg geometry) had cascading effects on mating parts.
- **Challenge:** Translating rotational hand-crank input into smooth, stable vertical lift required careful gear system design within the confined space of the desk legs.
- **Takeaway:** Reinforced the importance of designing shared reference geometry early so downstream components mate correctly as the assembly grows in complexity.

## Future Improvements
- Add a locking mechanism to hold height position without continuous crank tension
- Motorize the crank system for powered height adjustment
- Conduct a load/stability analysis at maximum extended height
