# Engineering Portfolio

Hi, I'm Ashmal. This repository is a collection of my independent and collaborative mechanical/electrical design projects, spanning CAD modeling, 3D printing, gear systems, electromagnetics, and mechanical testing. Each subfolder below is a self-contained design with its own README covering the overview, tools used, and key takeaways.

> This repository is shared for portfolio purposes. Designs here are finished pieces of work rather than actively-developed open source projects, so forking is disabled — feel free to reach out if you'd like to discuss any of them directly.

## Designs

- **[Gear Ratio System](./Gear%20Ratio%20System)** — A 3D-printed compound gear train (Fusion 360) achieving a 512:1 reduction, used to study high gear ratios and PLA durability under torque.
- **[Magnetic Induction Generator](./Magnetic%20Induction%20Generator)** — A magnet-wheel generator that converts rotation into rectified DC power via electromagnetic induction, built within a 6-inch print-bed constraint.
- **[Standing Desk](./Standing%20Desk)** — A fully custom, hand-crank-adjustable standing desk (SolidWorks) with integrated cable management, lamp mount, headphone stand, and storage drawer.
- **[Welding Test](./Welding%20Test)** — A bend-test rig (SolidWorks) for validating weld quality against AWS standards ahead of production welds, built for Rutgers Formula Racing chassis fabrication.
